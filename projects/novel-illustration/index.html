01 / THE PROBLEM

The problem

Indonesian novel narratives contain visual details, settings, and a distinctive illustration style. This final project explores adapting a pretrained text-to-image model to that context through LoRA fine-tuning.

Project focus

Generate illustrations from novel narratives, then evaluate how well the results follow the intended style and content.

02 / MY CONTRIBUTION

My contribution

I prepared the image–caption data, fine-tuned SDXL using LoRA, generated illustrations, and evaluated the resulting images as part of my final project.

Data and experiments

Dataset preparation, captioning, training configurations, and generation experiments.

Evaluation and analysis

Comparison of image quality, prompt alignment, visual similarity, and human feedback.
