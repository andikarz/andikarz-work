01 / THE PROBLEM

The problem

Industrial information is often accessed through predefined screens and menus. The OpAlpha chatbot provides a text-based way to ask questions within the application’s supported scope.

Completed implementation. Documentation only.

This case study presents the chatbot feature I developed. It does not provide access to OpAlpha or a live chatbot session.

02 / MY CONTRIBUTION

My contribution

I developed the chatbot feature using regex and fuzzy matching, without an LLM or trained AI model. The portfolio highlights that feature rather than claiming ownership of the entire OpAlpha application.

Pattern-based matching

Use regex rules to recognize supported question patterns.

Approximate matching

Use fuzzy matching to compare text variations against supported examples.

03 / HOW A QUESTION IS HANDLED

How a question is handled

Regex and fuzzy matching are the confirmed components. The sequence below is a documentation prototype to adapt to the actual implementation.

  1. 01

    Input preparation

    Normalize the query as required by the implementation.

  2. 02

    Regex rules

    Look for a supported question pattern.

  3. 03

    Fuzzy matching

    Compare variations when exact patterns are insufficient.

  4. 04

    Response or fallback

    Return a supported response or indicate that the question is not recognized.

Matching is not semantic understanding.

Similar wording can carry different meaning. Document how supported patterns, thresholds, and fallback behavior help limit incorrect responses. Database integration and other components should be added only if implemented.
